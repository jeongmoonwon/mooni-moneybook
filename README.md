# mooni의 가계부

누구나 구글 로그인만 하면 쓸 수 있는 가계부 웹앱이에요.

- **입력하면 자동 저장:** 저장 버튼을 누르면 바로 클라우드에 동기화돼요. 인터넷이 끊겨 있어도 입력할 수 있고, 연결되면 알아서 올라가요.
- **어느 기기에서든:** 앱을 지웠다 다시 깔거나 휴대폰을 바꿔도, 구글 로그인만 하면 기록이 그대로 있어요.
- **내 데이터는 나만:** 사람마다 데이터가 따로 저장되고, 다른 사람은 볼 수 없어요.
- **내보내기:** 내역 탭 → **내보내기**에서 두 가지 방법으로 받을 수 있어요.
  - **CSV 파일:** 엑셀에서 바로 열려요.
  - **구글 스프레드시트:** 내 구글 드라이브에 새 시트로 만들어져요.

## 처음 한 번만 — 앱 열기 (관리자만)

다른 사용자는 이 과정 없이 주소만 열면 돼요.

### 1. Firebase 만들기 (로그인 + 데이터 저장소, 무료)
1. [console.firebase.google.com](https://console.firebase.google.com)에서 **프로젝트 추가**를 눌러요. 애널리틱스는 꺼도 돼요.
2. **Authentication → 시작하기 → Google**을 **사용 설정**해요.
3. **Firestore Database → 데이터베이스 만들기**를 눌러요. 위치는 `asia-northeast3 (서울)`으로 해요.
   - 만든 뒤 **규칙** 탭에 [firestore.rules](firestore.rules) 내용을 붙여넣고 **게시**해요.
4. ⚙️ **프로젝트 설정 → 내 앱 → 웹(</>)**으로 앱을 추가해요.
   - 나오는 `firebaseConfig` 값을 [firebase-config.js](firebase-config.js)에 옮겨 적어요.

### 2. GitHub에 올려서 앱 주소 만들기
5. GitHub에 새 저장소를 만들고 이 폴더를 올려요. `data/` 폴더(내 소비내역)는 자동으로 빠져요.
6. 저장소의 **Settings → Pages**에서 Branch를 `main` / `(root)`로 고르고 **Save**를 눌러요.
   - 잠시 뒤 `https://아이디.github.io/저장소이름/` 주소가 생겨요. 이 주소가 앱이에요.
7. Firebase **Authentication → 설정 → 승인된 도메인**에 `아이디.github.io`를 추가해요.

### 3. 구글 스프레드시트 내보내기 켜기
8. [console.cloud.google.com](https://console.cloud.google.com)에서 위에서 만든 Firebase 프로젝트를 골라요.
   - **API 및 서비스 → 라이브러리**에서 **Google Sheets API**를 **사용**으로 바꿔요.
9. **OAuth 동의 화면**이 "테스트" 상태라면 **앱 게시**를 눌러요. 테스트 상태에서는 등록한 사람만 로그인할 수 있어요.

## 사용하기 (모든 사용자)

1. 앱 주소를 열고 **Google로 시작하기**를 눌러요.
2. 휴대폰에서는 **공유 → 홈 화면에 추가**(아이폰) 또는 **⋮ → 앱 설치**(안드로이드)를 누르면 앱처럼 쓸 수 있어요.
3. 예전 내역이 있으면 ⚙️ 설정 → **CSV 가져오기**로 불러와요.
   - 내 weple 내역: `data/이전내역_변환.csv`
   - 이 앱에서 내보낸 CSV도 다시 가져올 수 있어요. 이미 있는 기록은 건너뛰어요.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html`, `style.css`, `app.js` | 앱 화면 |
| `store.js` | 로그인 · 동기화 · 구글 스프레드시트 내보내기 |
| `firebase-config.js` | 내 Firebase 프로젝트 연결 정보 (공개돼도 괜찮아요) |
| `firestore.rules` | "자기 데이터만 보기" 보안 규칙 |
| `manifest.webmanifest`, `sw.js`, `icons/` | 홈 화면 설치 · 오프라인 실행 |
| `tools/migrate.py` | weple 내보내기 파일 → 가져오기용 CSV 변환 |
| `data/` | 내 소비내역 (git에 안 올라감) |

## 알아두면 좋은 것
- **무료 한도:** Firebase 무료 한도는 하루 읽기 5만·쓰기 2만 번이에요. 개인이나 지인끼리 쓰기에는 충분해요.
- **카테고리 바꾸기:** [app.js](app.js) 맨 위의 `CATS`를 고쳐요. 바꾸면 모든 사용자에게 똑같이 적용돼요.
- **내 컴퓨터에서 미리 보기**
  - `firebase-config.js`가 비어 있으면 `index.html`을 더블클릭해서 **데모 모드**로 볼 수 있어요.
  - 설정을 채운 뒤에는 파일을 바로 열면 로그인이 안 돼요. 폴더에서 `python3 -m http.server`를 실행하고 `http://localhost:8000`으로 열어요.
