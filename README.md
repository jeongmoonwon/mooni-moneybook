# mooni의 가계부

구글 로그인만 하면 쓸 수 있는 가계부 웹앱이에요. 휴대폰 홈 화면에 설치해서 앱처럼 쓸 수 있어요.

**앱 주소:** https://jeongmoonwon.github.io/mooni-moneybook/

- **입력하면 자동 저장:** 저장 버튼을 누르면 바로 클라우드에 동기화돼요. 인터넷이 끊겨 있어도 입력할 수 있고, 연결되면 알아서 올라가요.
- **어느 기기에서든:** 앱을 지웠다 다시 깔거나 휴대폰을 바꿔도, 같은 구글 계정으로 로그인하면 기록이 그대로 있어요.
- **내 데이터는 나만:** 사람마다 데이터가 따로 저장되고, 다른 사람은 볼 수 없어요.

---

## 설치하기

1. 앱 주소를 열고 **Google로 시작하기**를 눌러요.
2. 홈 화면에 추가해요.
   - **아이폰:** Safari로 열기 → 공유 버튼 → **홈 화면에 추가**
   - **안드로이드:** Chrome으로 열기 → ⋮ → **앱 설치**

## 화면 구성

| 탭 | 하는 일 |
|---|---|
| **홈** | 앱을 켜면 맨 위에 이번 달 소비 목표가 보여요. 그 아래 리뷰할 소비, 참은 소비, 지출 정도를 색 점으로 보여주는 달력(공휴일은 빨간 숫자)이 이어져요. 날짜를 누르면 그 날 기록이 보여요. 오른쪽 아래 **+** 버튼으로 지출 · 수입 · 저축 · 투자를 기록해요. 자주 쓰는 상세내역은 버튼으로 나와요. |
| **한 달** | 총 예산 대비 남은 돈과 쓴 돈, 카테고리별 지출 비율 원그래프(가운데에 평소 대비 %), '카테고리별 예산'을 펼치면 카테고리마다 예산 대비 쓴 돈(전체 예산을 입력하거나 막대를 끌어서 정하면 모든 카테고리에 똑같이 나눠 넣고, 동그란 손잡이를 끌어서 조정해요. 총 예산은 카테고리 예산의 합이에요), 저축 · 투자 금액, 소비 만족도(필수 · 만족 · 후회 비율), 참은 소비 목록, 카테고리별 금액을 보여줘요. 예산은 달마다 정하고, 정하지 않은 달은 직전에 정한 달의 예산을 그대로 써요. ▲▼는 최근 1년 월평균 대비 변화예요. |
| **내역** | 기록을 달 · 구분 · 카테고리로 걸러 보고 검색해요. **내보내기**로 CSV 파일이나 내 구글 드라이브의 스프레드시트로 받을 수 있어요. |
| **추이** | 월별 지출 또는 수입 꺾은선 그래프예요. 평소(직전 12개월 평균)의 1.5배 넘는 달은 피크로 표시돼요. |

## 설정 (⚙️)

- **가계부 이름:** 앱 맨 위 제목이에요. 비워 두면 "mooni의 가계부"로 보여요.
- **화면 모드 · 글씨체:** 기기 설정 따라 / 항상 밝게 / 항상 어둡게, 글씨체는 기본 · 고운돋움 · 푸어스토리 · 개구 · 하이멜로디 · 감자꽃 · 주아 중에서 골라요. 이 기기에만 저장돼요.
- **'한 달'의 시작일:** 이 날부터 다음 달 이 날의 전날까지를 한 달로 봐요. 월급날로 맞추면 편해요. 예: 25일이면 9/25~10/24가 "10월"이에요. 수입·지출 모두 실제 날짜가 이 기간 안에 있으면 그 달 기록이에요.
- **카테고리:** 추가 · 삭제 · 이름 바꾸기 · 순서 바꾸기(▲▼). 이름을 바꾸면 예전 기록에도 적용돼요.
- **소비 리뷰:** 고른 카테고리(기본: 전체)의 지출 중 정한 금액(기본: 5만원) 이상인 것을, 쓴 날로부터 정한 날짜(기본: 7일) 뒤에 홈에서 "지금 돌아보니 어때요?"라고 물어봐요. 필수 · 만족 · 후회 중 하나를 고르면 돼요.
- **CSV 가져오기:** 이 앱에서 내보낸 CSV나 예전 가계부 내역을 불러와요. 이미 있는 기록은 건너뛰어요.

## 관리자용

### 처음 한 번만 설정하기
1. **Firebase (로그인 + 데이터 저장소, 무료)**
   - [console.firebase.google.com](https://console.firebase.google.com)에서 프로젝트를 만들어요.
   - **Authentication**에서 Google 로그인을 켜요.
   - **Firestore Database**를 `asia-northeast3 (서울)`에 만들고, **규칙** 탭에 [firestore.rules](firestore.rules) 내용을 붙여넣어 **게시**해요.
   - **프로젝트 설정 → 내 앱 → 웹**으로 앱을 추가하고, `firebaseConfig` 값을 [firebase-config.js](firebase-config.js)에 옮겨 적어요.
2. **GitHub Pages (앱 주소)**
   - 저장소 **Settings → Pages**에서 Branch를 `main` / `(root)`로 고르고 **Save**해요.
   - Firebase **Authentication → 설정 → 승인된 도메인**에 `아이디.github.io`를 추가해요.
3. **구글 스프레드시트 내보내기**
   - [console.cloud.google.com](https://console.cloud.google.com)에서 같은 프로젝트를 골라 **Google Sheets API**를 **사용**으로 바꿔요.
   - **OAuth 동의 화면**이 "테스트" 상태라면 **앱 게시**를 눌러요.

### 코드를 고친 뒤
`main` 브랜치에 올리면(push) 1~2분 뒤 앱 주소에 자동으로 반영돼요. 휴대폰 앱은 한 번 껐다 켜면 새 버전이 떠요.

### 내 컴퓨터에서 미리 보기
폴더에서 `python3 -m http.server 8765`를 실행하고 http://localhost:8765 를 열어요. `localhost`는 Firebase에 기본으로 허용돼 있어서 로그인도 돼요.
`firebase-config.js`의 값을 비우면 로그인 없이 그 브라우저에만 저장되는 **데모 모드**로 열려요.

### 파일

| 파일 | 역할 |
|---|---|
| `index.html`, `style.css`, `app.js` | 앱 화면 |
| `store.js` | 로그인 · 동기화 · 구글 스프레드시트 내보내기 |
| `firebase-config.js` | Firebase 프로젝트 연결 정보 (공개돼도 괜찮아요) |
| `firestore.rules` | "자기 데이터만 보기" 보안 규칙 |
| `manifest.webmanifest`, `sw.js`, `icons/` | 홈 화면 설치 · 오프라인 실행 |
| `tools/migrate.py` | 예전 가계부(weple) 내보내기 파일 → 가져오기용 CSV 변환 |
| `data/` | 개인 소비내역. `.gitignore`로 저장소에 올라가지 않아요. |

### 알아두면 좋은 것
- **무료 한도:** Firebase 무료 요금제(Spark)는 하루 읽기 5만 · 쓰기 2만 번이에요. 개인이나 지인끼리 쓰기에는 충분하고, 넘으면 그날만 멈추고 요금은 나오지 않아요.
- **기본 카테고리:** [app.js](app.js) 맨 위 `DEFAULT_CATS`는 처음 쓰는 사람의 기본 목록이에요. 이미 쓰는 사람의 카테고리는 각자 설정에서 바꿔요.
